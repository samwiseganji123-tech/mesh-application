# Mesh – Social Media Application

Mesh is a social media application designed to connect people, encourage interaction, and provide a platform for sharing content. The project demonstrates full-stack web development using modern frontend and backend technologies.

## 🚀 Project Overview

Mesh is a full-stack application developed as part of my software development journey. It combines a responsive React frontend with a Node.js backend and MongoDB database.

The project focuses on creating an interactive user experience while demonstrating frontend development, backend API integration, and database connectivity.

## ✨ Features

- Responsive and interactive user interface
- React-based frontend
- RESTful API integration
- Backend built with Node.js and Express.js
- MongoDB database integration
- Modern component-based architecture

*Additional features will be documented as development progresses.*

## ⚙️ Installation and Setup

### Prerequisites

Ensure you have the following installed:

- Node.js
- npm
- Git
- MongoDB Atlas account or MongoDB instance

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project:

```bash
cd project-connect
```

### 2. Set up the frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend will typically run at:

```text
http://localhost:5173
```

### 3. Set up the backend

Open another terminal:

```bash
cd backend/server
npm install
```

Configure your environment variables in a `.env` file.

Example:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Start the backend:

```bash
npm start
```

The backend will typically run at:

```text
http://localhost:5000
```

## 🔐 Environment Variables

For security reasons, sensitive credentials should never be committed to GitHub.

Ensure your `.env` file is included in `.gitignore`.
